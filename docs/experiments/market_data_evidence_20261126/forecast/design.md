# 無料市場データ追加の4時間予測比較

2026-11-26。新規の研究用比較。既存キャンペーンとは別の出力に保存する。

- BTC単独のD03最終トークン84列、直近実現分散、EWMAが対照。追加群はETH、アルト10銘柄の市場横断統計、Bybit先物・建玉、Deribit DVOL、Coinbase BTC/USD、Coinbase USDT/USD。単独追加6種と全追加、対照で8条件。共通の完全観測日時のみ。新規の市場値はバー終了からさらに15分遅らせる。過去の到着時刻は再現不能。
- 各foldで直前24か月をTrain、その次の3か月をVal、最後の1か月でValを集計。以後最大3か月を既知の歴史Testとする。7fold、3か月ずつ移動。終点が区間境界以上のラベルは除外。各foldで同じTrain日時・設定・評価日時。線形モデル及びLightGBMを3目的別に学習。木は120ラウンド等を固定。期間・特徴・ハイパーパラメータをTestで調整しない。
- 主指標は4時間内に直前BTC終値から下・上に各2%到達する確率のBrierと、4時間実現分散のQLIKE。小さいほどよい。補助的に平均適合率、上位リスク群と全体の発生率、過去分散とEWMAを評価する。
- 追加の効果は同じモデルの対照からの平均損失差。各fold内のUTC暦日を使った対応あり循環7日ブロックbootstrap（10000回）。帰無中心化した両側p値、各splitの42比較（7追加条件×2モデル×3目的）をHolm補正。各splitの信頼区間は個別95%。Valは探索、既知Testは記述的な再現確認であり、両方の月には重複がある。未使用の未来holdoutでの検証は別。
