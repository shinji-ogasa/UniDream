# 固定リスク予測と持続性ベースラインの比較登録 — 2026-09-05

この文書・実装・設定・テストを**今回の比較結果を計算する前にコミット**する。
既存HGBの予測結果と以前の実験結果は観測済みである。比較する期間は再利用した
開発用validationであり、未観測データでの検証、正式P1、統計的有意性の主張ではない。
今回の得点からモデル・方策を順位付け・選択せず、既存選択ロックを変更しない。

## 固定する対象

- 入力：`codex_outputs/oracle_frontier_v1` の登録・結果・保存予測。
  設定で登録と結果のファイルSHA256を固定し、元の登録が束縛するソースコード、
  データ証明、39個のHGB予測NPZと39個のモデルファイルを検証する。
- 対象モデル：base16 / technical / flow の固定HGB・24本先（6時間）予測。
  新規学習、パラメータ調整、再校正は行わない。
- 対象期間：元のfold 0〜12のvalidation、2020-01-16 13:45 UTC以上、
  2023-04-16 13:45 UTC未満。元のtest区間は評価対象にしない。
- 3つの持続性ベースライン：直近 **24 / 96 / 672本**の二乗対数リターンの
  観測平均に24を掛けた将来分散を予測し、その平方根をRMS予測とする。
  正確には `sqrt(24 * trailing_mean(log(close_s/close_(s-1))^2))` を1本遅らせる。
  このRMSは24本先の平方根実現変動に対応し、年率化や平均リターンの控除はしない。
  将来ターゲットは元実験と同じ次足始値からの区間内対数価格増分を使用する。
- 全ベースラインの時点tの入力はt−1以前。完全な15分格子、窓全長の経過、
  `ceil(.995 * window)` 以上の有限リターンを要求する。欠損足の前後をつなぐ
  リターンを作らず、欠損埋めも行わない。測定された一定価格の分散は0とする。

## 同じ評価行での比較

元実験の全3特徴群の有限行と6時間刻みの判断時点を再構成し、保存済みの
`inference_mask` と一致を確認する。元の `score_support`、3モデルと3ベースライン
の有限かつ非負のRMS予測、有限な実現値をすべて満たす行だけで全系列を比較する。
ターゲットは再計算して保存済み実現値と照合し、ラベルの観測終了
`t + (24+1)*15分` がvalidation終了以下であることを再確認する。
欠損や期間末で除外した行を別の系列だけに戻さない。

各四半期に格子行数、元の判断行数、期間末条件通過数、実現値の有効行数、
最終共通評価行数を保存する。相場区分は元実験の四半期最初の判断時点で既知の
90日モメンタム / 7日ボラティリティから固定した上昇・下落・横ばいを維持する。
四半期中の将来価格で区分を再分類しない。

## 事前固定の損失と集計

`a` を実現RMS、`f` を予測RMSとして、次の3損失を全系列で計算する。

1. 主比較：分散MSE `mean((a^2-f^2)^2)`。
2. 主比較：QLIKE `mean(y/p-log(y/p)-1)`。`y=max(a^2,1e-12)`、
   `p=max(f^2,1e-12)` とし、測定された0だけに床を設ける。欠損は床で置換しない。
3. 元実験との対応確認：RMS MSE `mean((a-f)^2)`。

四半期別・相場区分別・全体について、各損失の四半期単純平均と評価行数で
重み付けしたプール平均を別々に示す。3 HGB × 3ベースラインの全組み合わせで
損失比、差、モデルの損失が小さい四半期数を保存する。相対損失減少は
`1 - 四半期平均モデル損失 / 四半期平均ベースライン損失`。
ベースライン損失が0の場合、比を未定義として残す。
これは学習期間平均を基準にした元実験のclimatology MSE skillとは異なる。

出力は `codex_outputs/oracle_risk_baselines_v1/{registration.json,results.json}`。
各foldの `rowwise/foldN.npz` に完全格子の時刻、共通評価mask、系列ID、
RMS・分散の実現値と予測値、3損失の行別配列を保存し、SHA256を結果に残す。
未評価行の損失はNaNである。後日のMBB等に使う場合は依存性の扱いを別に登録する。
本診断で信頼区間、有意差、一般化確率、運用成績の改善は算出・主張しない。
