# 符号・値幅のOracle診断結果（Stage16）

今回の固定コントローラでは、**将来リターンの符号を正解にする改善余地が大きい**ことを確認しました。
符号だけを未来の正解に置き換えると、平均AlphaEXは+14.769〜+18.022pt、MaxDDdeltaは
−10.519〜−11.113ptでした。対応する既存方策との差はAlphaEX+11.156〜+17.015pt、
DDdelta−4.254〜−5.131pt。値幅だけの置換は、TechnicalでAlphaEXを小幅改善する一方でDDを悪化させ、
PerpではAlphaEX・DDを両方悪化させました。

これは未来の情報を与えた診断です。**新しい因果的モデルはまだ得られておらず、最強モデルとは呼べません。**
符号を実際に予測できるか、値動きが大きいときにも安定するかは別途検証が必要です。
この結果は、次の研究で方向の予測情報を優先して調べる根拠になります。

sign置換のMSE低下は数式上の性質で、fullのMSE0も定義から決まります。
これらを学習で達成した精度や汎化の証拠として扱いません。逆に、値幅置換は誤符号時に
予測が−yとなり、損失4y²になるため平均二乗誤差（MSE）を拡大しました。

abs(mu)はE[abs(Y)]の推定値ではなく、条件付き平均の絶対値です。sign(mu)も最頻方向とは
限りません。この診断から「値幅モデルが弱い」「符号だけ学習すれば十分」とは結論しません。

実現y=0がfold8の2022-03-16 00:00 UTCに1時刻あり、両親とも元のmuは正でした。値幅置換するとmu=0となり、
既存の二値指標 (>0) でその1件の一致判定が変わります。両親を合わせて2件と数えた監査値を、
独立な2市場イベントと扱いません。元mu=0の採点行は0件でした。

## 次の因果的な検証へ

この診断では方向情報の改善余地が大きいと分かりました。今回の固定方策では、
元の符号のまま値幅を未来の正解に置き換えても、DDは改善しませんでした。
次は未来の符号を与える処理から離れ、既存の情報だけで方向を予測できるかを調べます。
通常の方向損失と、fit期間の値幅を反映した損失を固定した比較にすることが候補です。
新しい閾値・重み・モデルをこの結果だけで採用せず、単純対照・時系列分割・失敗基準を
別途事前登録してから計算します。モデル構造の探索は引き続き後回しです。

符号と値幅の予測可能性は条件付き平均の予測可能性と同じではなく、両成分の依存も関係します。
[Anatolyev–Gospodinov](https://pages.nes.ru/sanatoly/Papers/Decomp.pdf)の分解と、
