# 短期価格・フロー指標の固定比較結果（Stage15）

短期の価格5指標・フロー3指標・両方8指標を追加した全6方策は、今回も採用しません。
既存と同じ標準化Ridge100・同じ時刻集合で比較すると、評価期間の平均MSEは
価格+0.18463%、フロー+0.08352%、両方+0.10830%悪化しました。
全6方策の平均AlphaEXは負で、全相場でAlphaEX正・MaxDDdelta負という条件も未達です。
既存モデルの再現差は0で、特徴量追加の結果として失敗を保存します。

フロー・両方の追加は、同じ欠損処理の旧raw方策に対して平均AlphaEXとDDdeltaの両方を
改善しました。ただし予測誤差は悪化し、B&H超過利益は平均でも正になっていません。
この部分改善を、トレンドによらず精度が上がった証拠とは扱いません。

## 比較条件と読み方

2021年4月〜2023年4月の元validation5–12、8四半期を再利用しています。
元test(f)=validation(f+1)という別名関係があり、独立確認ではありません。
追加test15–24は今回の学習・ラベル・採点・選択に使用していません。
元SpotローダーはParquet全体をdecode後にcutoffで切るため、後続期間のバイトを
一切読んでいないという主張ではありません。モデル構造・窓幅・正則化の探索はありません。

元29指標に、1/4/12時間リターン・直近足の実体符号・終値位置を加えた34指標、
Spot/UMの1時間takerフロー・Spot出来高活動比を加えた32指標、両方の37指標を比較。
新37は以前のderivative37とは別です。新指標は完成済み足から作り、最後に1足shift。
相関した座標の追加はRidgeの実効的な正則化も変えるため、個別指標の情報価値は同定できません。

各foldはfit18か月、S3か月、I3か月、E3か月。32学習は既存再現8回＋追加24回です。
予測平均はfitだけで学習し、追加の補正・重み推定はありません。
分散は旧technical_scaledを共通使用し、リスクモデルの再学習は0回です。
Iは診断専用で選択に使いません。同一foldのIとEは非重複ですが、foldをまたぐと
Iが前foldのEと重なり、学習履歴も再利用するため独立な追試ではありません。
元の6マスクを保持し、推論2,586件と採点2,574件を混同していません。

BTCUSDT 15分足から6時間ごとに判断し、次足始値で約定、24足後終値までのlog-returnを予測。
ラベル確定は判断から375分後。fit/S/Iは区間末尾より前、E採点は末尾以下で確定したラベルを使い、
当該時刻のラベル可用性を推論・注文の条件にしていません。
B&H初期保有、目標保有率0.5〜1.12、1回変更0.08、deadband0.01、片道費用0.00055、
年率借入費0.10を固定。holdは予測欠損時に注文せず、fallbackは現在始値が分かれば目標1の注文を提出します。
自分の現金・保有量から注文を作り、欠損の即時次足約定は見送り、先送りしません。
2倍コストは同じ基準注文を再生します。比率を100倍したptで表示し、
AlphaEX正・MaxDDdelta負がB&Hに対する望ましい符号です。表は等重み四半期平均です。

## 判断と次の問い

短期特徴量追加を採用せず、174個の累積探索方策名に全失敗を含めて記録します。
従来のreliability候補に残る開発平均の良い符号も、新しい独立確認を得たわけではありません。
モデル構造は引き続き変更しません。短時間の符号予測の文献に着想を得た今回の固定特徴群では、
遅延約定を伴う6時間平均リターン予測の改善を確認できませんでした。

次は窓幅を成績に合わせて追加する前に、同じ実行条件で得たOracleの大きな改善余地と、
因果的予測の弱さの間を調べます。必要な情報が符号・振幅・大変動時のどこにあるかを、
新しい仮説・対照・失敗基準を事前固定した診断で切り分ける方針です。これはまだ実行して
いない次の問いであり、今回の結果から新しい教師や売買方策を作成したものではありません。

文献上の条件付きmomentum/reversalは全相場保証を意味せず、bar taker-flowは板イベント
imbalanceとは別です。詳細と一次資料は研究ノートに記載しています。
繰り返し使用した8四半期、重なる学習・評価履歴、2/4/2の相場件数、受信時刻証跡の欠如、
適応的な探索履歴が残ります。独立確認・高確率の全相場汎化・正式P1・最強モデルは未成立です。
