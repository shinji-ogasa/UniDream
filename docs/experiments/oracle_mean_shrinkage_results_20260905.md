# 固定50%縮小による予測・経済成績の改善

先物フローを使う平均収益予測を、過去の校正期間の平均へ50%縮めると、欠損時は保有を続ける候補で **AlphaEx +3.613pt、MaxDDDelta −5.388pt** となった。費用・借入金利2倍では **+3.349pt、−5.305pt**。元の予測に対してMSEは3.697%、MAEは2.706%改善し、両指標とも全8四半期で改善した。

これは改善方向を示す開発結果である。MSEはゼロ予測や単純な過去平均にまだ負けており、各トレンドの期間数は2/4/2で最低3期間の条件を満たさない。全四半期で経済条件を満たしたわけでもない。158候補名に至る適応的探索で繰り返し使った期間であり、最強モデル・独立確認・高確率の将来保証とは判定しない。

## 比較条件

[事前登録](oracle_mean_shrinkage_registration_20260905.md)、設定、実装、テスト、データだけを確認するpreflightをコミット `3957975` で固定してから計算した。学習構造は変えず、保存済みのStandardScaler + Ridge(alpha=100)平均予測と、全候補共通のtechnical_scaled HGB分散予測を使用した。

新しい平均予測は `mu_half = 0.5 * scale_mean + 0.5 * mu_scaled` の2種類だけである。scale_meanは評価開始の6〜3か月前の校正期間から得た定数であり、直近3か月平均ではない。50%は計算前に固定し、新しい学習、追加の校正、重み探索は行っていない。technical_halfとperp_delay0_halfを、欠損時に保有を続けるルールと、既知の現在価格で目標比率1を提出する既存fallbackルールで比較した。各候補が自身の現金・保有量に基づいて意思決定する。

評価はvalidation folds 5–12、[2021-04-16 13:45 UTC, 2023-04-16 13:45 UTC)。同じ2,586推論行・2,574採点行、6時間ごとの決定、次の15分足始値での約定、24本先の予測を維持した。片道費用0.00055、年間借入金利0.10、最大変更幅0.08、deadband 0.01、目標比率範囲[0.5,1.12]。実保有比率は価格変動で範囲外へ動くことがある。費用2倍は元の目標を再生し、意思決定を再最適化していない。

## 予測精度

改善率は `1 - 四半期平均損失(candidate) / 四半期平均損失(reference)`。各四半期の改善率を平均した値ではない。正は誤差減少、負は悪化。比較する行は同一で、保有ルールが異なっても予測そのものは同じである。

| 新予測 | 比較相手 | MSE改善率 | MAE改善率 | MSE改善期間 | MAE改善期間 |
|---|---|---:|---:|---:|---:|
| テクニカル・50% | 元予測 | +4.143% | +3.017% | 8/8 | 8/8 |
| テクニカル・50% | 校正期間の平均 | -1.892% | -1.414% | 1/8 | 1/8 |
| テクニカル・50% | ゼロ予測 | -2.600% | -2.118% | 2/8 | 1/8 |
| テクニカル・50% | 学習期間の平均 | -2.359% | -1.969% | 4/8 | 1/8 |
| 先物フロー・50% | 元予測 | +3.697% | +2.706% | 8/8 | 8/8 |
| 先物フロー・50% | 校正期間の平均 | -1.545% | -1.176% | 2/8 | 2/8 |
| 先物フロー・50% | ゼロ予測 | -2.250% | -1.879% | 3/8 | 2/8 |
| 先物フロー・50% | 学習期間の平均 | -2.010% | -1.730% | 4/8 | 2/8 |

50%混合は同じ行で `MSE(half) = 0.5*MSE(full) + 0.5*MSE(anchor) - 0.25*mean((full-anchor)^2)` を満たす。この性質が保証するのは両端の平均損失以下という点であり、よい方の端点を上回ることではない。今回、元予測より全8期間で改善したことは実測結果である。先物50%でも平均予測よりMSEは1.545%悪く、予測精度の課題は残る。

各四半期のrank ICは元予測と一致した。正の係数と定数による変換は四半期内の順位を変えないため、今回の改善は順位予測の改善ではなく、予測の大きさと取引量の調整に関係する。四半期ごとに平均が異なるので、全期間をまとめたrank ICが不変とは限らない。先物・保有継続では平均売買回数が57.625→29.750、回転量が4.232→2.089へ減った。費用低下だけで成績差すべてを説明したという因果分解ではない。

独立実装による目標・トレース・AlphaEx・DD・取引費用の最大差は0。平均保有比率の差は2.22e−16、MSE混合恒等式の誤差は5.42e−20。将来ラベルが採点不能な48推論決定も注文判断に残っている。欠損のないfold8/10/11では、半分予測の保有継続とfallbackが6組とも一致した。これは元の100%予測と一致するという意味ではない。

`uv run python -m unittest discover -s tests -v`: **537 tests OK (56.481s)**。既存モデルの再学習を別実装で追試した監査ではなく、保存予測、変換、注文・会計・集計の独立確認である。

入力の共通マスクはアーカイブで再構成した比較用の支持集合で、当時の受信時刻を証明しない。2,920予定決定のうち推論可能2,586、既知現在価格で予測がないfallback対象332、現在始値なし2。長い特徴量窓が少数の欠損価格を長い推論停止へ波及させる問題と、ライブ受信の証拠不足は残る。

## 一次資料との関係

[Rapach–Strauss–Zhou (2010)](https://doi.org/10.1093/rfs/hhp063) p.845 Eq.(23)の過去平均への縮小という見方を動機とした。米国株式プレミアムの予測を扱う研究であり、今回の単一Ridgeと3か月平均の50%混合がBTCで最適だと示すものではない。[Goyal–Welch–Zafirov (2024)](https://doi.org/10.1093/rfs/hhae044)の再検証も、探索に使った過去期間と独立した確認を区別する理由になる。

[How to Dominate the Historical Average (2025)](https://doi.org/10.1093/rfs/hhaf010)も確認した。過去平均への小さな補正が優位となる定理には、真の係数の符号・補正幅や誤差分布などの条件がある。今回の固定50%はその条件を検証しておらず、BTCでの確率的優位を継承しない。この論文から追加の係数や重みを選んではいない。
