# 予測不能時のB&H比率復帰：DD改善とAlphaExの代償

予測不能時にB&H比率へ戻す一律ルールは、先物scaled候補の全体MaxDDDeltaを改善したが、開始時bear区分のAlphaExを負に変えた。新7候補で、観測された全開始時区分の平均の両符号を維持したものは0だった。このルールをトレンド非依存の改善として採用する根拠は得られなかった。

改善と悪化が大きい2期間は、開始時の相場区分と実現した値動きが逆だった。fold5は開始時bullだが実際のB&Hは−47.766%、fold6は開始時bearだが+92.069%。B&H比率へ戻すことで急落時の損失は抑えられたが、上昇時のレバレッジ利益も減った。データ可用性・予測精度・経済リスクは別々に評価する必要がある。

## 何が改善し、何が悪化したか

fold5ではscale_mean、technical_scaled、perp_scaledの新方策は同じ保有経路となった。先物scaledのAlphaExは−6.176ptから−1.936ptへ4.240pt改善し、DD差は+6.505ptから+2.356ptへ4.149pt改善した。改善後もその期間ではB&Hを下回り、DDも大きい。最初のfallbackは2021-04-20 06:00 UTC、既知始値での実比率1.13674から目標1を提出した。

一方fold6では、先物scaledのAlphaExが−0.142ptから−5.680ptへ5.538pt悪化した。DD差は+2.513ptから+1.314ptへ1.199pt改善。最初のfallbackは2021-07-24 06:00 UTC、実比率1.11045からの調整であり、fallback判断時の実比率は1.0〜1.13174だった。この主要な悪化を「低保有からの強制買い増し」と説明することはできない。B&Hが92.069%上昇した期間に、レバレッジを落とした保有経路と整合する。ただし同時に後続の学習判断も変わるため、差額全体を最初の売却だけに帰属させない。

先物scaledの開始時bear区分のペア差は、すべてfold6から生じた。他の同区分fold8/10/11はfallback対象が0で、元の目標と成績に完全一致する。開始時のトレンド分類は因果的に利用可能でも、後続四半期の実現トレンドを保証しない。

元の予測値・採点行は完全固定なので、今回MSE・MAE・rank ICが改善したという主張はない。scale_mean / technical_scaled / perp_scaledの平均売買回数は8.25 / 50.625 / 62.125回、平均回転は0.558 / 3.644 / 4.563となった。DDの改善だけでも、AlphaExの改善だけでも目標達成とはしない。

## 次の仮説

一律B&H復帰の採用は保留する。今回の主な悪化がレバレッジの削減である以上、「買い増しだけ禁止すれば解決する」とは推定できない。短い履歴だけで動く特徴量や障害時の別予測を使う場合も、入力の可用性と精度を別途事前固定して調べる必要がある。

次はモデル構造を維持し、前の平均対照で誤差の大きかったモデル変動成分を固定で半分にする比較を優先する。式は `mu_half = scale_mean + 0.5 * (mu_scaled - scale_mean)`。technicalとperpの両方、欠損時保有継続と今回のB&H復帰の両方を比較し、都合の良い組合せを先に採用しない。λ=0、1の既存対照と新しい0.5を同じ支持行で比較し、新しい窓長やハイパーパラメータ探索は加えない。この仮説は未実行であり、次の登録後に測る。

利用可能な予測だけの誤差とcoverageを分ける考え方は、[Geifman–El-Yaniv (2017)](https://proceedings.neurips.cc/paper/2017/file/4a8423d5e91fda00bb7e46540e2b0cf1-Paper.pdf)にもあるが、そのiid分類保証はBTC保有に適用できない。[Rubin (1976)](https://doi.org/10.1093/biomet/63.3.581)の欠損の無視可能性も仮定つきであり、共通maskが全期間への一般化を証明するわけではない。[Jorion (2003)](https://doi.org/10.2469/faj.v59.n5.2565)が扱うベンチマーク相対リスクと総リスクの違いも、目標1を無リスクと解釈しないための参考であり、今回の規則の最適性やDD保証を示すものではない。
