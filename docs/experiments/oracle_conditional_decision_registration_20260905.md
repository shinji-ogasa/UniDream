# Conditional decision v1 registration

Fixed before outputs from this family. Prior calibration and48+24policy outcomes
have been observed. This is another adaptive reused-validation diagnostic;
there is no new test/outer stage, deployment, or strongest-model declaration.

The90% return interval gate produced no meaningful trades; raw point-to-target
mapping may instead spend too much turnover without accounting for its current
inventory. Test a small explicit conditional utility optimizer before changing
model architectures or training an RL student.

Nine policies: previously frozen calibrated base16 HGB / technical HGB / HAR
variance forecasts with their shared calibrated return mean, crossed with
risk aversion{0,1,4}. Cost budget multiplier is fixed at2. No new fitting occurs.
At each6h UTC decision, observe current open and own cash/units inventory,
never current close or next fill price. Consider hold and feasible target
changes of-.08,-.04,+.04,+.08 bounded to[.5,1.12], with the existing deadband.

Relative to holding, evaluate

    (p-current)*mu - .5*lambda*(p*p-current*current)*predicted_variance
    - 2*one_way_cost*abs(exact_trade_notional/current_nav)
    - (max(p-1,0)-max(current-1,0))*borrow_annual*24/35040.

Choose a trade only if its score strictly exceeds the zero hold score. The
trade notional uses current known open; actual next-open fill can differ and
is re-clipped to the same execution max-step. When passive inventory has drifted
outside target bounds, score only the current-open max-step projection toward
the bounded intent; do not score an unreachable immediate rebalance. This is an estimated local
optimizer for an explicitly approximate quadratic log-utility. It is not a
Bayes-optimal oracle or a global optimizer of MaxDD. The2x round-trip budget is
a decision heuristic; accounting charges actual one-way fills and borrowing.

All targets are generated by causal replay of each policy's own inventory,
then canonically replayed under base and2x actual costs. Stress retains the
same base-cost selected intents, as in prior diagnostics. Same quarters,
past-defined regimes, grids, costs, masks and data cutoff. Source registration,
model/forecast artifacts and code are hash-bound. Preserve all9 outcomes and
unchanged point controls; do not change any earlier selection lock.
